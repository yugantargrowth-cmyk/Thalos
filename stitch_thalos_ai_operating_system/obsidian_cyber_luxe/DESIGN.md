## Brand & Style

This design system establishes a high-tier cybernetic operating environment that bridges elite computational infrastructure with haute-couture technological refinement. Created for specialized sovereign operations, telemetry control, and advanced algorithmic synthesis, the visual language commands absolute technological authority, quiet confidence, and cinematic precision.

The target audience comprises system architects, quantitative directors, and sovereign operators who navigate mission-critical networks where telemetry clarity and hyper-refined aesthetic prestige must coexist.

### Visual Aesthetic & Movement
The design system combines **Hyper-Futuristic Cybernetics** and **Ultra-Luxury Glassmorphism**:
- **Void Obsidian Canvases:** Deep, atmospheric backgrounds that banish flat slate-grays in favor of layered vacuum-space depths.
- **Controlled Luminescence:** Cyan and teal photonic emissions that cut through darkness with laser-etched sharpness rather than diffuse neon clutter.
- **Glassmorphic Chassis:** High-refraction semi-translucent planes bound by gossamer structural borders and precise linear accents.
- **Ceremonial Clearance Gates:** Selective gold-tier accents deployed strictly to denote state-level clearance, high-value algorithmic transactions, and privileged execution pathways.

## Colors

The color architecture is built strictly for high-fidelity dark mode, prioritizing chromatic luminance balance across pure photonic emitters and deep spectral voids.

### Palette Architecture
- **Primary (`#00f3ff` / `#00d2df`):** Electric Neon Cyan. Denotes operative status, active data streams, system focus, and interactive vector boundaries.
- **Secondary (`#00e5c9`):** Synthetic Teal. Applied to secondary computational threads, verified states, and stabilized system nodes.
- **Tertiary (`#ffd166` / `#ffb703`):** High-Clearance Imperial Gold. Reserved exclusively for executive directives, privileged security tiers, financial payloads, and warning overrides.
- **Neutral Void Spectrum:**
  - Base Void: `#02060b` (Deepest canvas backing)
  - Surface Mid: `#050d15` (Primary card and modular chassis backdrops)
  - Surface Elevated: `#081420` (Flyouts, raised diagnostic docks, and contextual overlays)
  - Border Substrate: `rgba(0, 243, 255, 0.14)` (Resting structural grid lines)
  - Text Primary: `#e6f6f8`
  - Text Muted: `#5c778a`

## Typography

The typographic hierarchy harmonizes ergonomic structural readability with terminal-grade telemetry precision.

- **Display & Headlines (Plus Jakarta Sans):** Carries modern, geometric posture with tightly tracked characters. Used for high-impact module headers, executive telemetry totals, and system section titles.
- **Body & Explanatory Text (Inter):** High-efficiency neutral legibility optimized for density without optical fatigue across deep-dark surfaces.
- **Data, Telemetry & Clearance Labels (JetBrains Mono):** Reserved for technical metrics, coordinates, hex addresses, timestamp arrays, and protocol badges. All status indicators and caps labels use uppercase formatting with widened tracking (`0.12em`).

## Layout & Spacing

The layout model executes a 12-column rigid cybernetic chassis system bound by an underlying 8px rhythmic sub-grid.

### Layout Principles
- **Grid Structure:** A 12-column responsive layout spanning variable master displays. Column divisions align directly with faint structural grid lines (`rgba(0, 243, 255, 0.05)`).
- **Desktop (1440px+):** Fluid canvas with `margin-desktop` boundaries, housing floating operational panels, modular multi-pane telemetry grids, and fixed diagnostic HUD columns.
- **Tablet (768px - 1439px):** 8-column restructuring with secondary telemetry panels folding into expandable drawer modules.
- **Mobile (Below 768px):** Single-column stacked telemetry stack with sticky system-node action docks and anchored bottom-rail terminal navigation.

## Elevation & Depth

Spatial separation relies on back-projected optical blurs and luminous vector outlines, bypassing mud-inducing soft black dropshadows.

### Structural Stratification
1. **Basal Plane (Level 0):** Pure `#02060b` vacuum backing etched with an optional geometric millimeter coordinate grid in subtle alpha lines.
2. **Glassmorphic Chassis Panels (Level 1):** Solid `#050d15` tinted at 75% opacity, paired with a `16px` to `24px` backdrop Gaussian blur. Rimmed with a continuous `1px` translucent edge: `border: 1px solid rgba(0, 243, 255, 0.12)`.
3. **Active Interactive Nodes (Level 2):** Elevated cards and active dialogs featuring concentrated backdrop blurs (`32px`), with an inner edge glow: `box-shadow: inset 0 0 12px rgba(0, 243, 255, 0.06), 0 8px 32px rgba(2, 6, 11, 0.8)`.
4. **Focused / Breached Layer (Level 3):** Modal overlays and critical clearance gates bound by luminous cyan/gold perimeter lines with atmospheric outer halo projections (`box-shadow: 0 0 24px rgba(0, 243, 255, 0.25)` or `0 0 24px rgba(255, 209, 102, 0.25)`).

## Shapes

The geometric architecture avoids aggressive circularity, leaning into architectural, precision-machined forms.

- **Corner Radii:** Standard components feature `0.25rem` (4px) soft chamfers, communicating high-density engineering, chip-level microarchitecture, and militarized computing equipment.
- **Modular Panels & Viewports:** Extended panels, cards, and modal windows scale up to `rounded-lg` (`0.5rem` / 8px).
- **Accent Clipping:** Terminal badges, status pills, and high-clearance triggers may feature subtle 45-degree angle clipped corners (cybernetic diagonal cuts) across top-right or bottom-left vertices.

## Components

### Buttons & Interactive Triggers
- **Primary Neon Emitters:** Cyan background (`#00f3ff`), black typography (`#02060b`), font weight 600. On hover, emits a focused photonic plume (`box-shadow: 0 0 16px rgba(0, 243, 255, 0.5)`).
- **Secondary Glass Triggers:** `#081420` surface with `1px solid rgba(0, 229, 201, 0.4)` perimeter, teal text (`#00e5c9`), and background luminescence transitions on hover.
- **Gold Clearance Buttons:** Imperial gold fill (`#ffd166`), jet-black label, strictly deployed for destructive actions, security authentication overrides, and high-tier capital allocations.

### Cards & Telemetry Panels
- Crafted with frosted obsidian backplanes (`rgba(5, 13, 21, 0.8)`), dynamic backdrop blur (`20px`), and `1px` gradient border strokes shifting from cyan (`rgba(0, 243, 255, 0.3)`) to transparent void.
- Headers are marked by monospaced classification tags (`label-caps`) alongside geometric node state lights.

### Input Fields & Data Terminals
- Deep obsidian fill (`#02060b`), crisp border (`rgba(0, 243, 255, 0.2)`), typography set in `code-lg` with cyan cursor caret.
- Active focus state transitions the border to illuminated primary cyan (`#00f3ff`) backed by a localized glow (`box-shadow: 0 0 8px rgba(0, 243, 255, 0.25)`).

### Clearance Badges & Chips
- Compact dimensions using `code-sm` font, with translucent backgrounds and saturated borders.
- Gold Clearance status uses `background: rgba(255, 209, 102, 0.08)` and `border: 1px solid rgba(255, 209, 102, 0.5)`.
- Nominal Status uses Teal/Cyan variants.

### Selection Controls (Checkboxes & Radios)
- Squircular and angular profiles with `1px` cyan borders.
- Checked state fills the interior with an inner illuminated neon core and outward glow.

### Specialized Additions: Cyber Grid Rails & HUD Scanners
- Subtle linear coordinate tickers, scanning telemetry lines, and crosshair corners framing critical visualization canvases to reinforce an authentic sovereign OS paradigm.
