# DEFECTS REGISTER & RESOLUTION: MISSION S06 — NERVOUS SYSTEM

| Defect ID | Description | Root Cause | Resolution | Verification |
|---|---|---|---|---|
| **D-S06-01** | Unbounded exponential backoff could overflow or cause infinite retry delays | Backoff calculation was `Math.pow(2, job.attempt) * 30000` without an upper bound. High attempt counts produced unreasonably long retry intervals. | Capped exponential backoff at 1 hour (3,600,000 ms) using `Math.min(delay, 3600000)`. | Verified in `tests/unit/jobStateMachine.test.ts`. |
| **D-S06-02** | Permanent errors (e.g. malformed CSV, syntax errors, missing handler) triggered useless retries | All errors were treated identically as retryable as long as `job.attempt < job.max_attempts`. | Introduced `classifyJobError()` and `PermanentJobError`. Permanent errors immediately set `willRetry = false` and fail without retry. | Verified in `tests/unit/jobStateMachine.test.ts`. |
| **D-S06-03** | Workflow definitions lacked static graph verification, allowing cyclic step deadlocks | `WorkflowRuntime` assumed workflow definitions were valid DAGs without validating self-dependencies or circular loops. | Added `validateWorkflowDefinition()` with DFS graph coloring cycle detection before execution. | Verified in `tests/unit/workflowEngine.test.ts`. |
| **D-S06-04** | Burst worker polling could race and exceed `maxConcurrency` | Concurrency check checked `activeJobs.size < maxConcurrency` prior to async `claim_next_job`, allowing concurrent poll ticks to both claim before either entry was inserted into `activeJobs`. | Added `inFlightClaims` reservation counter checked atomically before initiating RPC claim. | Verified in `tests/unit/workerTelemetry.test.ts`. |
| **D-S06-05** | Failed steps with `on_failure: 'continue'` were re-executed in infinite loop | In `runStepLoop`, `remainingSteps` only excluded `stepsCompleted`, so steps in `stepsFailed` were repeatedly selected. | Excluded both `stepsCompleted` and `stepsFailed` from remaining steps when continuing after failure. | Verified in `tests/unit/workflowEngine.test.ts`. |
